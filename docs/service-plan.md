# SwingPost サービス計画（2026年11月時点・暫定）

ゴルフのレッスンプロが、インスタのフォロワーにスイング動画の添削を月額で売れる場所。生徒は動画を送るだけで、画像つきの添削が届く。

> 本書の数字のうち、出典つきのもの以外は仮定・試算です。料金やルールは「暫定」で、検証で見直します。

---

## 1. 背景と課題

### コーチ側

- インスタやYouTubeで発信していても、それを収入に変える仕組みを持っていないプロが多い。対面レッスンは商圏に縛られる。
- オンライン添削を売っているコーチは、汎用のオンラインサロン基盤（FANTSなど）、動画配信の会員サービス、LINEと振込などを組み合わせている。添削の道具（コマ送り、線引き）と受付・集金が分かれていて手間がかかる。
- 添削は1件20〜40分かかるとされ、人気コーチほど手が回らない。

### 生徒側

- インドアスクールは通う手間がある。YouTubeは自分のスイングを見てもらえない。
- AIのスイング解析は安いが、人に見てもらう安心感や継続の動機にはならない。

## 2. 解決策

**「コーチがLINEより速く添削できて、集金まで済む、ゴルフ専用の場所」**

- 受付ページ（コーチのプロフィールリンク）から、生徒が月額で申し込み、動画を送る。
- コーチは、自動で切り出されたキー位置（アドレス／トップ／インパクト／フィニッシュ）に線を引き、理由をテキストで書いた**添削カード**で返す。
- 生徒はLINE通知から閲覧ページを開き、カード・ドリル・チャットで次の練習につなげる。

## 3. ターゲット

| 対象             | 内容                                                                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 最初に狙うコーチ | インスタでレッスン系の発信を続けている中堅のティーチングプロ・セミプロ（フォロワー数千〜数万人）。添削を売る仕組みがない、またはサロン基盤やLINEで手作業している人 |
| 生徒             | そのコーチのフォロワー。スクールに通うほどではないが、自分のスイングを見てほしい人                                                                                 |

### 規模の目安（推定）

| 段階                                 | 人数           | 根拠                                                                         |
| ------------------------------------ | -------------- | ---------------------------------------------------------------------------- |
| 国内でゴルフを教えている人           | 1万〜2万人     | PGA会員約5,600人（2019年）、JLPGA会員約1,400人、資格なしの指導者を加えた推定 |
| インスタでレッスン発信を続けている人 | 1,000〜3,000人 | 1〜2割と仮定                                                                 |
| 生徒を集められそうな層               | 300〜1,000人   | 3〜4割と仮定                                                                 |

月50万円に必要な稼働コーチは40〜50人なので、狙い目の5〜15%が乗れば届く。

### 人気コーチの実例（調査時点）

- 三觜喜一：独自アプリで会員限定動画、月1万円（添削の記載なし）
- 菅原大地：manateaで動画見放題、月650〜980円（添削は抽選特典のみ）
- 川合杏奈：FANTSで添削月1回8,800円、月4回22,000円（限定20名）
- 宮田志乃：FANTSで月2,980円、個別フィードバック月2回つき11,000円

上位の人気コーチは動画配信が主で、添削を主力にしているのは中堅層。

## 5. サービスの仕組み

### 申し込み（承認制・暫定）

- 生徒は**悩みと動画を送り、カードを登録（仮押さえ）**して申し込む。この時点では請求しない（どのプランも同じ）。
- コーチは悩みと動画を見て、**48時間以内に受けるか決める**。受けたら請求が確定してスレッドが始まり、断ったら（理由とひとことを添えて）仮押さえを外す。期限までに決めなければ自動で断った扱いにする。
- 苦手な内容を断れるようにするため。承認のあとに支払う形にしないのは、生徒が戻ってこない・支払われないまま動画を見ることになるのを避けるため。
- コーチが不在のあいだは新しい申し込みを受け付けない。承認待ちも受付枠に数える。お試しは承認待ちでも「使った」扱い（断られたら戻る）。
- 月額は、初月を同じく仮押さえし、承認したら初月を確定して、同じカードでサブスクリプションを始める（2回目の請求は30日後）。2か月目からは承認なしで毎月請求し、請求ごとにスレッドを作る。断ったらサブスクリプションは作らない。

### スレッド（暫定）

- 1スレッド＝生徒は**提出3回まで**（お試しは1回）。1回の提出で**動画2本まで**（正面と後方など）送れ、角度（正面・後方・その他）を選ぶ。動画は**1本60秒まで**。
- コーチは**提出ごとに1回**添削を返す。カードはその提出のどの動画からでも作れる。前の提出に添削が届くまで、次は提出できない。
- チャットは**スレッドに1本の時系列**。生徒は**合計30通まで**（お試しは10通）で、提出の回数とは別に数える。最初の提出のあとから送れる。コーチは無制限。
- 期限は開始から**30日**（申し込みは、コーチが承認した時点から。延長の扱いは未定）。期限を過ぎ、すべての提出に添削を返したら終わる。
- 生徒は、添削待ちの提出がなければ、期限の前でも自分でスレッドを終えられる（返金はしない）。終わったら LINE でレビューをお願いする（レビューは星とコメント。コーチは返信できる）。
- 1つのテーマ（例：トップの右ひざ）を「送る→直す→撮り直して送る」で最後まで見る。
- コーチは月の**受付枠**（例：20人）を設定でき、満枠ならキャンセル待ちを受け付ける。

### 返信の形

- テキスト中心の**添削カード**（キャプチャ画像＋線＋理由）。音声は主にしない。
- 閲覧ページはWeb、通知はサービス共通のLINE公式アカウントから1通。
- 生徒登録はLINEログイン（予定）。

## 6. 料金（暫定）

### 生徒向けの初期設定（コーチが変更可）

| プラン    | 価格       | 最低価格 | 内容                                 |
| --------- | ---------- | -------- | ------------------------------------ |
| お試し    | 550円      | 550円    | 提出1回・チャット10通までのミニ添削   |
| 1スレッド | 4,980円    | 3,980円  | 提出3回・チャット30通まで・30日間     |
| 月額      | 3,980円/月 | 3,980円  | 毎月1スレッド（提出3回・チャット30通まで） |

- コーチは最低価格以上で自由に決める（安売り防止）。
- 生徒は価格とは別に、**申し込みごとにシステム利用料（価格の5%と200円の高いほう。円未満切り捨て）**（税込。月額は毎月、お試しにもかかる）を払う。価格が4,000円以下なら200円。月額を値下げしたときは利用料も新しい価格で計算し直す。システム利用料はプラットフォームの収入で、コーチの売上には影響しない。コーチが断った・期限切れの申し込みでは請求しない。返金では一緒に返す。
- 価格を変えたとき：お試し・1スレッドは申し込んだ時点の価格のまま。月額の**値上げは新しく申し込む人から**（いまの生徒は据え置き）、**値下げはいまの生徒にも次の請求から**反映する。

参考：インドアスクール（ステップゴルフ）は月5,478円から。添削の相場は1回1,000〜5,000円、月額3,000〜15,000円（一般ブログの数字）。

### コーチ向け

- 基本は無料、手数料**10%**（決済手数料込み）。
- 将来：コーチ向け定額プラン（例：月4,980円で手数料を決済実費のみ）。
- 将来：コーチ一覧（マーケットプレイス）経由の生徒は手数料15〜20%を検討。コーチが自分で連れてきた生徒は10%のまま。
- 下限価格（安売り防止）は上の最低価格。

## 7. 収益モデルと試算

手数料10%からカード決済（3.6%）とStripe Connectの費用（稼働アカウント月200円、入金ごとに0.25%＋250円）を引くと、手元に残るのは**約6%**。

| 平均単価                  | 稼働コーチ × スレッド/月 | 流通額/月 | 手取り/月 |
| ------------------------- | ------------------------ | --------- | --------- |
| 4,500円                   | 30人 × 20                | 270万円   | 約17万円  |
| 4,500円                   | 60人 × 30                | 810万円   | 約52万円  |
| 6,000円                   | 50人 × 25                | 750万円   | 約48万円  |
| 8,000円（人気コーチ中心） | 35人 × 25                | 700万円   | 約45万円  |

- コーチ1人あたりの上限は月20〜30スレッド程度（1スレッド1〜2時間と仮定）。
- 上限を押し上げる手：自動キャプチャとドリル登録で添削を速くする、満枠のコーチが値上げする、コーチ向け定額プラン。
- 目標：副業として月10〜20万円、頑張って月50万円。
- 原価：AIは1件1円前後（推定）。動画の保存費用は未試算。

### 出口

月50万円の利益が安定すれば、売却も選択肢。小規模Webサービスは営業利益の2〜3年分前後が一つの目安（年500万円なら1,000万〜1,500万円程度）。売り先は個人向け売買サイト、またはゴルフ関連企業。高く売るには、属人化しない運営、特定コーチへの偏りの少なさ、継続率の記録、規約と契約の整備が必要。

## 8. 機能ロードマップ

### 段階0：Webモック（いま）

- 受付ページ、コーチのホーム、添削画面、閲覧ページ、LINE通知の見た目
- 動画のスロー再生、コマ送り、線引き、カード化、チャット（モックデータ）
- 目的：コーチへのDMで見せる、Webで動画まわりが実用になるか確かめる

### 段階1：手動運用（コーチ3人）

- 自動キャプチャ（1コマずつ補正可）、スロー再生、線引き、テキストのカード返信、チャット
- 受付と集金は決済リンクで代用
- 目的：生徒が払うか、添削が速くなるかを測る

### 段階2：正式リリース

- 受付ページ、月額の自動集金（Stripe Connect）、入金管理
- 閲覧ページ＋LINE通知、LINEログイン
- 前回との比較、お試し枠、受付枠とキャンセル待ち
- **ドリル登録**：やり方・説明・動画を登録し、添削で使い回す（最初は空で開始）
- **コーチのレビュー**：スレッド完了後に生徒が星とコメントを残せる。コーチは返信可

### 段階3：コーチが増えてから

- コーチを探して選べる一覧（マーケットプレイス）。載るかはコーチが選択
- 一覧経由の手数料の差別化

### 後で検討

- AI下書き、切り抜き動画の自動作成、声の添付、マイドリル
- コーチ個人のLINEアカウントからの送信

## 9. 集客

- **コーチ集め**：インスタでレッスン発信を頑張っているコーチに直接アプローチ。訴求は「全国からオンラインで手軽に収入」。
- **生徒集め**：コーチ自身の告知に任せる。こちらは「コーチが広めやすくなる道具」を出す（受付ページ、受付枠の表示、お試し枠、コーチ紹介の特典）。
- 広告はこちらで出さない（生徒1人あたりの取り分が小さいため）。出すならコーチの添削切り抜きをコーチ自身が少額で宣伝する形。
- 手動運用で「告知から何日で何人埋まったか」を記録し、次のコーチへの実績として見せる。

## 10. 検証計画と判定基準

| ステップ | 内容                                       | 進む目安（仮）                                            |
| -------- | ------------------------------------------ | --------------------------------------------------------- |
| 1        | オンライン添削を売っているコーチを数える   | 50人以上見つかる                                          |
| 2        | 10人に聞き取り（今の受付・集金・困りごと） | 不満があり「試す」と言う人が3人以上                       |
| 3        | 3人と4週間の手動運用                       | 有料の生徒が合計15人以上。コーチの1件あたり作業時間も測る |

払う側（生徒）は「大丈夫」という仮説で進めるが、ステップ3で必ず確かめる。

## 11. リスク

- **コーチ集めは実質的に営業**：相手は個人でDMで済むが、40〜50人まで増やすにはコーチ紹介の仕組みが鍵。
- **コーチ1人あたりの上限**：添削の時間に縛られる。
- **人気コーチ依存**：上位数人に売上が偏ると不安定。
- **直接取引への流出**：固定客がついたコーチが手数料を避けて直接取引に移る。対策はコーチ側の便利さ、チャットのサービス内化、規約での連絡先交換の禁止。
- **運用の手間**：返金、返信遅れ、トラブル対応。期限とルールを先に決める。
- **既存の汎用基盤**：MOSHは手数料約6.5%＋99円と安い。

## 12. 決済・法務

- **Webで提供**：Appleのアプリ内課金の免除はリアルタイムの1対1のみで、後から返信する形は対象外と判断された例がある。
- **資金を預からない**：Stripe Connectでコーチへ送金し、取り分を差し引く形。国内の収納代行の扱いは専門家に確認。
- **特定商取引法の表示**：誰が出すかを要確認。
- **レビュー**：見返りつきのレビュー依頼は景品表示法のステマ規制に触れるおそれがあるので規約で禁止。
- **個人情報**：生徒の動画の扱いを規約に明記。切り抜きの投稿は生徒の同意が前提。
- **売却時**：個人事業の事業譲渡になるため、税理士に相談。

## 13. サービス名・デザイン

- サービス名：**SwingPost**（暫定）。商標（J-PlatPat：第9類・第41類・第42類）とドメイン（swingpost.com / .jp）は未確認。
- デザイン：白ベース、余白多め、角丸大きめ。差し色はブライトミント `#5FD4A0`、ボタンの文字は濃い緑 `#0B3D2C`。
- 技術：Webで開始（ネイティブアプリは後で検討）。Next.jsのAPIをvinextで動かし、Cloudflare Workersに置く。動画の保存・配信は将来Cloudflare R2（転送料なし）。骨格推定とコマの切り出しはブラウザ内で処理し、必要になれば重い処理だけ別環境に切り出す。正式リリース前にvinextとOpenNextを比較して最終判断する。
