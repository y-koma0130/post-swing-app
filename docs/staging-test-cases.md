# 本番リリース前の確認（staging・Stripe テストモード）

staging（https://staging.swingpost.app）で、Stripe のテストモードを使って申し込み〜支払い〜返金を通す。
金額は、コーチの価格を1スレッド4,980円・月額3,980円にした場合の例（システム利用料200円・手数料10%）。

## 準備

- [ ] staging の Stripe（テストモード）の Webhook が2つある：自分のアカウント用（`checkout.session.completed`・`invoice.created`・`invoice.paid`・`customer.subscription.deleted`）と Connect 用（`account.updated`）。送り先は `https://staging.swingpost.app/api/webhooks/stripe`
- [ ] テスト用のコーチが、売上の受け取り口座（Connect のテストアカウント）の設定まで終わっている（コーチのホームに「まだ申し込みを受け付けていません」が出ない）
- [ ] 生徒用に、LINE でログインできるテストアカウントがある（通知の確認用。公式アカウントを友だち追加しておく）
- [ ] カード番号：通常は `4242 4242 4242 4242`、拒否は `4000 0000 0000 0002`、本人認証（3Dセキュア）は `4000 0025 0000 3155`

確認する場所：Stripe のダッシュボード（支払い・サブスクリプション・Connect の送金・Webhook のイベント）、アプリの画面、LINE、コーチのメール。

## A. 1スレッド

| # | やること | 確かめること |
|---|---|---|
| A1 | 受付ページ →「申し込みへ進む」でプランを選ぶ | スレッドの画面（下書き）に移る。「申し込みの手順」が出る |
| A2 | 悩みと動画を送り、「カードを登録して申し込む」→ `4242…` で完了 | 画面が「コーチが内容を確認しています」になる。Stripe の支払いが **未確定（Uncaptured）・5,180円**、明細が「1スレッド 4,980円」「システム利用料 200円」の2行、手数料（application fee）698円、送金先がコーチの口座。コーチにメール「申し込みがありました」、コーチのホームの先頭に「申し込み（承認待ち）」 |
| A3 | コーチが「受ける」 | 支払いが **確定（Succeeded）**。コーチの口座へ 4,482円の送金。スレッドがレッスン中になり、期限は受けた日から30日。生徒に LINE「受け付けられました」。添削とチャットができる |
| A4 | 別の申し込みでコーチが「お断りする」（理由とひとこと） | 支払いが **取り消し（Canceled）**、請求なし。生徒の画面に理由とひとこと、「請求はされていません」。生徒に LINE |
| A5 | 支払い画面で「戻る」 | 下書きのまま。もう一度「カードを登録して申し込む」から進める |
| A6 | 支払い画面で `4000 0000 0000 0002`（拒否） | エラーになり、下書きのまま |
| A7 | 支払い画面で `4000 0025 0000 3155`（本人認証） | 認証のあと、承認待ちになる |
| A8 | 承認待ちのまま48時間（D1 のコンソールで `thread.requested_at` を3日前にして、毎日の処理（日本時間4:00）を待つ） | 断った扱い（期限切れ）になり、支払いが取り消し。生徒に LINE |

## B. お試し

| # | やること | 確かめること |
|---|---|---|
| B1 | お試しで申し込む（承認待ちまで） | 金額が価格＋200円。申し込みページで、お試しが「利用済み」になる |

## C. 月額

| # | やること | 確かめること |
|---|---|---|
| C1 | 月額で申し込む（承認待ちまで） | 支払いが未確定・4,180円（3,980円＋200円）。Stripe の顧客にカードが保存されている |
| C2 | コーチが「受ける」 | 初月の支払いが確定。**サブスクリプション** ができる：明細が「月額 3,980円」「システム利用料 200円」の2行、無料期間の終わりが受けた日から30日後、手数料の割合 14.31%、送金先がコーチ。0円の請求書が1枚できるが、スレッドは増えない |
| C3 | 2か月目：Stripe でそのサブスクリプションの「無料期間を今すぐ終了」 | 4,180円の請求書が払われる。新しい月のスレッドができる（コーチにメール「新しい月が始まりました」）。手数料 約598円、送金 約3,582円 |
| C4 | 別の月額の申し込みをコーチが断る | 支払いが取り消し。サブスクリプションはできない |
| C5 | 生徒がマイページの「月額の解約・カードの変更」から解約 | Stripe の画面で解約できる。申し込みが「解約済み」になる。いま進んでいるスレッドは期限まで使える |

## D. 価格の変更（月額）

| # | やること | 確かめること |
|---|---|---|
| D1 | コーチが月額を 4,980円にしてから、生徒が月額で申し込み、受ける | サブスクリプションが 4,980円＋200円 |
| D2 | コーチが月額を 3,980円に下げて保存 | 「月額を続けている1人も、次の請求から新しい価格になります」。サブスクリプションの価格が 3,980円になり、日割りの請求はない。手数料の割合が新しい価格に合う |
| D3 | コーチが月額を 5,980円に上げて保存 | いまのサブスクリプションは変わらない（新しく申し込む人だけ 5,980円） |
| D4 | 1スレッドを 3,000円にして保存 | 「価格は、お試し550円・1スレッド3,980円・月額3,980円以上に」で保存できない |

## E. 返金（管理画面）

| # | やること | 確かめること |
|---|---|---|
| E1 | 1スレッドのスレッドを返金 | 5,180円を全額返金。コーチへの送金を取り戻し、手数料も返す。スレッドが終了 |
| E2 | 月額の2か月目のスレッドを返金 | その月の請求（4,180円）だけを返金 |

## F. 終わり方・通知

| # | やること | 確かめること |
|---|---|---|
| F1 | 添削を受けたあと、生徒が「このスレッドを終える」 | スレッドが終了し、レビューを書ける。生徒に LINE「スレッドが終わりました（レビューのお願い）」 |
| F2 | Stripe のダッシュボードで `checkout.session.completed` を再送 | 承認待ちが2つにならない。コーチへのメールも増えない |

## G. キャンペーン（先行募集・手数料0%）

| # | やること | 確かめること |
|---|---|---|
| G1 | 管理画面でコーチを招待するとき「先行募集」を選ぶ | 「特典も付けました」。コーチの行に「先行募集（手数料0%）未開始」。招待の欄の残りが1つ減る |
| G2 | そのコーチの設定画面 | 「最初の生徒の申し込みを承認した日から90日間、手数料0%」 |
| G3 | そのコーチが初めて1スレッドを承認 | 確定した支払いの Application Fee がシステム利用料だけ（200円）。コーチへの送金が価格の100%。設定画面が「いまは手数料0%です（◯月◯日まで）」。管理画面の特典が「◯月◯日まで」 |
| G4 | 同じコーチが月額を承認し、2か月目の請求（「無料期間を今すぐ終了」） | 請求書の Application Fee がシステム利用料だけ（`invoice.created` で入れ直される）。手数料の差額を戻した記録はない |
| G5 | `invoice.created` の Webhook を一時的に外して、2か月目の請求を起こす | 10%＋利用料で請求されたあと、`invoice.paid` で差額が Application Fee の返金として戻る。翌朝の Cron のログに「手数料の差額を戻した請求」 |
| G6 | 管理画面で特典を「取り消す」 | 「取り消し済み」。招待の欄の残りが1つ戻る。次の承認から手数料10% |
| G7 | 期間が過ぎたあとの承認・月額の請求 | 手数料10%に戻る |
